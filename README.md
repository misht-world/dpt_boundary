# Схемы границ территорий

Локальное веб-приложение: рисуете границу территории на карте Санкт-Петербурга —
получаете готовый Word-документ («Приложение …» с картой, названием территории
и условными обозначениями) по образцу из `template/`.

## Запуск

Дважды кликнуть **`run.bat`** — запустится сервер и откроется браузер
(http://127.0.0.1:8077).

Требования: Python 3.10+ и пакеты из `requirements.txt`:

```
pip install -r requirements.txt
```

## Использование

1. Выберите подложку (OSM, Генплан СПб 2023, комбинации).
2. Инструментом «полигон» (или «прямоугольник») нарисуйте границу:
   клики — точки, замыкание — клик по первой точке;
   режим редактирования — перенос/удаление вершин; корзина — удалить контур.
3. «Показать надписи» — на карту добавятся названия улиц, населённых
   пунктов (галочками можно включить МО и районы). Надписи берутся из OSM
   (Overpass API) и кэшируются в `labels_cache/`. Любую надпись можно
   перетаскивать; клик открывает редактор (текст, поворот, категория,
   удалить); двойной клик — убрать. Поле «Своя надпись…» добавляет
   собственную надпись выбранной категории в центр рамки. Размер шрифта
   на листе фиксированный, регулируется ползунком «Масштаб надписей».
4. Заполните «Приложение №» и «Территория». Выберите «Тип объекта»:
   для линейного в документ добавится «Ориентировочная протяжённость — N,N км»
   (по самой длинной стороне контура), для площадного —
   «Ориентировочная площадь — N,N га» (геодезическая площадь контура).
5. Пунктирная рамка на карте — границы будущей картинки. Галочка
   «Рамка вручную» позволяет тянуть её за углы (перенос — кнопкой
   «Перенести слой» на панели карты); надписи и генерация используют
   именно её. Снятие галочки возвращает автоматическую рамку.
6. «Значок севера на схеме» — стрелка с «С» в правом верхнем углу картинки.
7. «Сформировать Word» — документ сохранится в `output/` и откроется в Word
   (там можно сделать «Сохранить как» в нужное место).

## Подложки и кэш

* Слои Генплана СПб 2023 (принятый) берутся с рендер-сервиса NextGIS
  (ecom.nextgis.com) анонимно, потайлово.
* Земельные участки Росреестра (ПКК) — тайлы NextGIS Geoservices
  (`pkk/ngrr2`, подключение опубликовано на ecom.nextgis.com, ресурс 691);
  доступны комбинации OSM/OpenTopoMap + Генплан + ЗУ.
* Все тайлы **навсегда кэшируются** в `tiles_cache/` — просмотренные места
  и повторная генерация работают без интернета и не зависят от сайта.
* Список подложек настраивается в `app/basemaps.py` (можно добавить любые
  XYZ-тайлы или другие слои вебкарты ecom.nextgis.com по resource id).

## Структура

```
app/main.py      — FastAPI-сервер (API + статика)
app/basemaps.py  — конфигурация подложек
app/tiles.py     — загрузка тайлов с дисковым кэшем
app/render.py    — склейка карты + отрисовка границы и надписей (Pillow)
app/labels.py    — надписи из OSM (Overpass API, с кэшем)
app/docgen.py    — сборка docx (python-docx)
app/static/      — фронтенд (Leaflet + Leaflet-Geoman)
template/        — исходные образцы Word
output/          — результаты
tiles_cache/     — постоянный кэш тайлов
```

## Импорт DXF (МСК-64)

Блок «Импорт границы из DXF»: выбрать систему координат чертежа
(МСК-64 СПб ГОСТ / расчётный вариант / WGS84), при необходимости порядок
осей (в геодезических чертежах X = север), выбрать файл — контур появится
на карте, дальше как обычно.

* Берётся наибольший замкнутый контур чертежа (LWPOLYLINE/POLYLINE/LINE);
  если замкнутых нет — самая длинная полилиния.
* Официальные параметры МСК-64 закрыты; используются общепринятые открытые
  наборы (см. `app/dxf_import.py`), точность порядка метра — для
  ориентировочных границ достаточно. При необходимости proj-строку можно
  подправить там же.
* DWG напрямую не читается — сохраните как DXF в CAD или сконвертируйте
  бесплатным ODA File Converter.
* Порядок осей «авто»: если оба варианта дают точки в окрестностях СПб,
  выбирается X=восток и выводится предупреждение — если контур лёг не туда,
  выберите порядок осей вручную.

## Сервер pi5

Приложение выложено на домашний сервер pi5 (ветка `pi5`).

* **Адрес:** https://boundary.taildd6b66.ts.net (🔑 вход по паролю, Funnel).
* **Данные на сервере:** `/opt/pi5/boundary/data` (`tiles_cache/`, `labels_cache/`,
  `output/`), том монтируется в контейнер как `/data` (переменная `DATA_DIR`).
* **Выкатить:** закоммитить в `pi5`, затем `scripts/deploy-pi5.sh`
  (копирует код на Pi и пересобирает контейнер; compose и метки — в
  `my_pi5-server/stack/boundary`).

Отличия серверного режима от ПК (переключаются переменными окружения,
локальный запуск через `run.bat` не меняется):

* `APP_PASSWORD` — пароль входа. Пусто → вход выключен (как на ПК).
  `SESSION_SECRET` — секрет cookie-сессии (генерируется на сервере).
* `DATA_DIR=/data` — кэши и готовые документы на постоянном томе.
* Word на сервере не открывается (`os.startfile` только на Windows) —
  документ **скачивается** по ссылке `/api/download/...`.
* Готовые `.docx` одноразовые: при каждой генерации удаляются файлы
  старше 1 часа (`OUTPUT_TTL_SECONDS`).
* Подписи на карте рисуются шрифтом Liberation Serif (ставится в образ,
  аналог Times New Roman с кириллицей).
